# SmartSport Design System

## Theme

Light-first sports booking interface. White and cool blue surfaces provide clarity; green, amber and coral accents distinguish sports and states.

## Typography

Use the existing system sans stack. Headings are bold and compact. Labels remain readable Vietnamese with restrained uppercase usage.

## Color

- Primary: blue for active selection and main actions.
- Success: emerald for availability.
- Attention: amber for rating and useful prompts.
- Accent: coral for location and reset actions.
- Neutral: slate for text, borders and quiet surfaces.

## Components

- Controls use 10-12px radius, visible focus states and lucide icons.
- Cards use 12-16px radius, one border layer and a clear image hierarchy.
- Filters use familiar buttons, selects and removable chips.
- Motion is limited to state transitions between 150ms and 250ms.

## Layout

Public discovery pages use a constrained wide content area, a compact filter workspace and a responsive results grid. Mobile prioritizes search, sport selection and progressive filter disclosure.
