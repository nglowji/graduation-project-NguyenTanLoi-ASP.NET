# Design

## Visual Theme
Modern, High-performance Sports Aesthetics.
- **Scene**: A dynamic sports environment, fast-paced and high-energy.
- **Color Strategy**: committed (Primary blue carries 40% of the accent weight).

## Colors
- **Primary**: `oklch(60% 0.25 250)` (Sporty Blue)
- **Secondary**: `oklch(70% 0.25 50)` (Energetic Orange)
- **Surface (Light)**: `oklch(98% 0.01 250)` (Off-white)
- **Surface (Dark)**: `oklch(15% 0.02 250)` (Deep Navy)

## Typography
- **Heading**: "Montserrat", sans-serif (Bold, geometric, strong)
- **Body**: "Plus Jakarta Sans", sans-serif (Clean, modern, readable)

## Components
- **Buttons**: Rounded (12px), bold labels, subtle hover lift.
- **Cards**: Soft shadows, generous padding, sharp image corners.
- **Filters**: Clean dropdowns, clear active states, grouped by category.

## Layout
- **Spacing**: 1.5, 2, 3, 4 rem rhythm.
- **Grid**: Responsive 12-column grid.
